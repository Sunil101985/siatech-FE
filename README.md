# Siatech Solutions — Enterprise website package

## Pages included
- `index.html` — Home
- `services.html` — detailed service pages/sections for Cloud & DevOps, AI & Automation, Cybersecurity, Software Development, IT Consulting
- `training.html` — IT training catalogue for AI/GenAI, AWS/Azure/GCP, DevOps, cybersecurity, software, data and IT tools; links to the supplied Google Form
- `about.html` — company purpose and principles
- `careers.html` — careers interest page, with an email link to `hr@siatechsolutions.com`
- `contact.html` — business enquiry form and address/contact details
- `styles.css` — responsive design, iconography and CSS 3D hero animation
- `script.js` — mobile navigation, year, contact email handoff
- `assets/siatech-logo.png` — your supplied company logo
- `assets/favicon.svg` — browser icon

## Publish
1. Extract the ZIP.
2. Back up your current website files.
3. Upload all HTML files, `styles.css`, `script.js` and the complete `assets` folder to your hosting public root (`public_html`, `www` or `htdocs`).
4. Ensure `index.html` is the default homepage.
5. Visit the site and test every navigation item, the phone/email links and the Google Form on mobile and desktop.
