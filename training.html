01AI, Generative AI & Agentic AIAI foundations · LLMs · RAG · agents · responsible AI+

Module 1 — AI foundations

AI/ML concepts, supervised vs. unsupervised learning, model lifecycle, evaluation and limitations.

Module 2 — Generative AI & LLMs

Tokens, context windows, embeddings, prompting patterns, structured outputs and model selection.

Module 3 — Retrieval-Augmented Generation

Document ingestion, chunking, embeddings, vector search, retrieval quality, citations and evaluation.

Module 4 — Agentic AI

Agent loops, tools and function calling, planning, memory concepts, multi-step workflows, guardrails and human approval.

Module 5 — Build & assess a use case

Prototype an assistant or workflow, test quality and failure cases, apply privacy/security checks and document trade-offs.

02Data Analyst & Business IntelligenceExcel · SQL · Python foundations · dashboards · storytelling+

Module 1 — Data foundations

Data types, data quality, cleaning, business questions and KPI definition.

Module 2 — Excel & spreadsheets

Formulas, lookup functions, pivot tables, charts and repeatable reporting.

Module 3 — SQL & relational data

SELECT, filtering, joins, aggregation, subqueries, window functions and query hygiene.

Module 4 — Python for analysis

Notebook workflow, pandas basics, cleaning, exploration and simple visualizations.

Module 5 — Dashboard & case study

Dashboard design principles, measures, filters, insights, presentation and a business-style capstone.

03Automation & ScriptingPython · APIs · workflow automation · Git · testing+

Module 1 — Programming essentials

Variables, collections, conditions, loops, functions, exceptions and clean code.

Module 2 — Files & APIs

CSV/JSON processing, REST basics, authentication concepts, HTTP responses and safe retries.

Module 3 — Practical automation

Automate repeatable file, reporting and operational tasks; logging, configuration and error handling.

Module 4 — Quality & delivery

Git workflows, unit tests, code review, secrets handling and scheduled execution concepts.

Module 5 — Capstone

Build a small automation utility with clear documentation, test cases and operational safeguards.

04Cybersecurity, Cloud Security & DevSecOpsIAM · secure SDLC · scanning · secrets · monitoring+

Module 1 — Security essentials

Threats, risk, least privilege, shared responsibility and basic security controls.

Module 2 — Identity & cloud protection

IAM/RBAC, MFA concepts, network boundaries, encryption, key management and logging.

Module 3 — Secure development

Threat modelling basics, dependency hygiene, secret scanning, SAST/DAST concepts and remediation.

Module 4 — CI/CD security

Pipeline controls, artifact integrity, approvals, policy checks and least-privilege deployment identities.

Module 5 — Detection & response

Audit logs, alerting, vulnerability triage, incident workflow and a secure delivery case study.
